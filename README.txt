XC MEET SPLIT TIMER — V1

Purpose
- Offline iPad timing for XC meets
- Four race levels: Varsity Girls, Varsity Boys, JV Girls, JV Boys
- One iPad can be set to Mile 1; the other can be set to Mile 2
- Names only; no bib numbers needed
- Big athlete buttons for rapid tapping
- Saves data locally on each iPad
- Export results as CSV after the meet

IMPORTANT
For iPhone/iPad offline installation, these files must be hosted over HTTPS at least once so Safari can install/cache the PWA. Opening index.html directly from the Files app will not install the service worker.

SETUP BEFORE A MEET
1. Open the hosted app while you have internet.
2. In Safari, tap Share > Add to Home Screen.
3. Open the installed app once while still online.
4. Tap Manage Rosters and save names for all four levels.
5. Optional: turn on Airplane Mode and reopen the app to verify it works offline.

AT THE MEET
IPAD 1:
- Select the race level.
- Select Mile 1.
- Load Race.
- Tap START RACE at the gun.
- Tap each athlete's name as they pass.

IPAD 2:
- Select the same race level.
- Select Mile 2.
- Follow the same process.

FEATURES
- Names disappear from Waiting after they are recorded.
- Recorded athletes display below with their split.
- Undo Last Tap corrects an accidental tap.
- Edit allows a split to be corrected manually.
- Start -1 sec / +1 sec lets a manager correct a slightly late or early race start.
- Save This Checkpoint stores the results on that iPad.
- Saved Results > Export CSV creates a spreadsheet-ready file.

NEXT STEP
The export can later be connected to the main XC Google Sheets / Apps Script system so Mile 1 and Mile 2 results automatically merge into athlete meet history when internet returns.
